Cotação de Dólar (React)

Este projeto é uma aplicação web desenvolvida em React para consultar a cotação do dólar (USD) em tempo real e converter valores entre Dólar e Real (BRL). A aplicação consome uma API pública para obter as taxas de câmbio atualizadas.

Funcionalidades

Consulta de cotação em tempo real: Exibe o valor atual do dólar (USD) em relação ao Real (BRL).

Conversão de valores: Permite converter um valor em BRL para USD e vice-versa.

Interface amigável: Design simples e fácil de usar.

Tecnologias

Frontend: React.js

Estado: React Hooks

API: Exchangerate API
 (ou qualquer outra API de câmbio que você preferir)
